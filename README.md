# AI-Assisted Smart Pet Care & Veterinary Management Platform

## Project Overview

The AI-Assisted Smart Pet Care & Veterinary Management Platform is a web-based application designed to help pet owners manage their pets' health and connect with veterinary professionals.

The platform provides a centralized system for managing pet profiles, veterinary appointments, medical records, vaccination schedules, and pet-care information.

It also includes an AI-assisted pet-care feature that provides general educational guidance and helps users understand common pet-care questions. It does not replace professional veterinary diagnosis or treatment.

## Main Objectives

- Help pet owners manage their pets' information.
- Make veterinary appointment management easier.
- Maintain organized medical and vaccination records.
- Provide reminders for important pet-care activities.
- Offer AI-assisted general pet-care guidance.
- Support veterinarians in managing appointments and pet records.

## Technology Stack

- **Frontend:** React, HTML, CSS, JavaScript
- **Backend:** Python, FastAPI
- **Database:** PostgreSQL
- **Development Tools:** Visual Studio Code, Git, GitHub
- **API Testing:** Postman
- **Documentation:** Swagger / OpenAPI

## Main User Roles

1. Pet Owner
2. Veterinarian
3. Administrator
